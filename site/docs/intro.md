# Ultimate DevOps to MLOps Bootcamp

> Take one machine learning model all the way to production, and keep it running. — by Gourav Shah, School of DevOps & AI.

A project-driven bootcamp for engineers who need to put machine learning models into production and operate them. You build a house price prediction service end to end: trained by a pipeline, packaged into a container, deployed on Kubernetes, monitored in Grafana, scaled by KEDA, and delivered through GitOps with Argo CD. No machine learning background is needed. Comfort on a command line is.

## Who this is for

DevOps and platform engineers supporting ML workloads, backend engineers moving toward ML infrastructure, and data scientists who want their models to reach production.

## How to use this course

Each module is a **Lesson** (concepts + analogies + diagrams), a **Lab** (copy-runnable, validated
live), and a **Quiz**. Work them in order; the project spine — A house price prediction service. One forked repository grown module by module, from raw CSV through to a GitOps-delivered, self-scaling inference service on Kubernetes. — grows across
modules into the capstone.
