# Course Slide Voiceovers

Private source only. Write one file per module at
`planning/voiceover/mN-slide-voiceover.md`.

Each file contains only words spoken over the concept deck, grouped under
`## Video N: <dual-use title>` headings. The title is used unchanged for the Udemy lecture and
YouTube episode. `[Slide N]` markers align speech to every non-divider slide.

Lab and deep-dive recordings use their validated learner guides directly. Do not create
screencast scripts, demo checklists, shot lists, a hands-on title map, or a fixed hands-on count.
